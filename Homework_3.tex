  {\Large \textbf{Energy-Efficient Computing}}\\[4pt]
  {\large Homework 3}
\end{center}

In this homework you will write a few small test programs in Python, Java, and C++ and
compare how much energy each one uses.

\textbf{Setup.} You must do all of your work on \texttt{pedagogical-3.cs.utexas.edu}, since
energy numbers are only comparable when measured on the same machine. Log in, then clone
the repo and work inside it:

\begin{verbatim}
    ssh <your-cs-id>@pedagogical-3.cs.utexas.edu
    git clone https://github.com/ATX24/hw_3_eec.git
    cd hw_3_eec
\end{verbatim}

To measure a program, put \texttt{./rapl} in front of the command you would normally use
to run it:

\begin{verbatim}
    ./rapl python3 test.py
    ./rapl java Test
    ./rapl ./test
\end{verbatim}

\texttt{rapl} prints how long your program ran and how much energy the CPU and memory
used. Add \mbox{\texttt{-r 5}} to run it 5 times. If \texttt{./rapl} does not run, rebuild it
with \texttt{make}.

Write each program the same way in all three languages. Do not use libraries that do the
work for you (like NumPy or built-in sort functions). Compile C++ with \texttt{g++ -O2}.

\begin{enumerate}[label=\textbf{\arabic*.}, leftmargin=*, itemsep=10pt]

\item Write a Python, Java, and C++ version of each program below. For each one, use
  \texttt{rapl} to get the energy of all three versions, then compare them.

  \begin{enumerate}[label=\textbf{\alph*.}, itemsep=4pt]
    \item Matrix multiply: two $400 \times 400$ matrices using a triple loop.
    \item Quicksort: 2,000,000 random integers.
    \item Mergesort: 2,000,000 random integers.
    \item Fibonacci: \texttt{fib(35)} using plain recursion.
  \end{enumerate}

\item Explain the differences you saw in Question 1. (Hint: run
  \texttt{./rapl sleep 10} to see how much energy the machine uses doing nothing.)

\item Research how garbage collection in the Java runtime affects energy usage.

\item Research RAPL (Running Average Power Limit) on Intel processors. How does the chip
  keep track of energy, and how can software read that data? Look at \texttt{rapl.c} to
  see how our tool does it.

\end{enumerate}

\textbf{Submit:} your source files and a PDF with your results and answers.
